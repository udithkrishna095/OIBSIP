# Task 3 - Car Price Prediction with Machine Learning

## Project Overview

This project is part of the **Oasis Infobyte Data Science Internship (OIBSIP)**.

The objective of this project is to predict the **selling price of used cars** using Machine Learning.

## Dataset

The project uses the **CarDekho vehicle dataset**.

The dataset contains:

- Car Name
- Year
- Selling Price
- Present Price
- Kilometres Driven
- Fuel Type
- Seller Type
- Transmission
- Owner

Dataset file:

`car data.csv`

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Steps

1. Load and explore the dataset
2. Check and clean the data
3. Handle missing values and duplicates
4. Create new features such as Car Age and Brand
5. Perform Exploratory Data Analysis (EDA)
6. Visualize the data
7. Encode categorical variables
8. Split the data into training and testing sets
9. Train regression models
10. Evaluate the models using MAE, RMSE, and R²
11. Select the best-performing model
12. Analyze feature importance

## Machine Learning Models

Two regression models were used:

- Linear Regression
- Random Forest Regressor

## Evaluation Metrics

The models were evaluated using:

- **MAE (Mean Absolute Error)**
- **RMSE (Root Mean Squared Error)**
- **R² Score**
