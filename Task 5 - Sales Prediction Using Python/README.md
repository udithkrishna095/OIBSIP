# Task 5 - Sales Prediction Using Python

## Objective
To build a Machine Learning model that predicts product sales based on advertising expenditure on TV, Radio, and Newspaper.

## Dataset
The project uses the **Advertising.csv** dataset.

Features:
- TV
- Radio
- Newspaper

Target:
- Sales

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Steps
1. Loaded and explored the dataset.
2. Checked data types, missing values, duplicates, and descriptive statistics.
3. Performed Exploratory Data Analysis using pairplots and scatter plots.
4. Analyzed correlations using a heatmap.
5. Split the data into training and testing sets.
6. Trained a Linear Regression model.
7. Trained a Random Forest Regression model.
8. Compared the models using MAE, RMSE, and R² Score.
9. Analyzed feature importance to identify the most influential advertising channel.
10. Used the best model to predict sales.

## Models Used
- Linear Regression
- Random Forest Regressor

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Conclusion
The project successfully predicts product sales using advertising expenditure. Linear Regression and Random Forest models were compared to find the better-performing model. Feature importance analysis was also used to identify which advertising channel has the highest influence on sales.

This project demonstrates how Machine Learning can be used for sales prediction and can help businesses make better advertising decisions.
